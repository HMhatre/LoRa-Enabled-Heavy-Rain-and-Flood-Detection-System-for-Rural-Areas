# LoRa-Enabled-Heavy-Rain-and-Flood-Detection-System-for-Rural-Areas
A dual-controller IoT-based flood monitoring system detects heavy rainfall and flood conditions using rain, water-level, ultrasonic, float-switch, and DHT11 sensors. The Arduino Nano transmitter sends real-time sensor data via 433 MHz LoRa (SX1278) to an ESP32 receiver. Both units display live readings on SSD1306 OLED screens
